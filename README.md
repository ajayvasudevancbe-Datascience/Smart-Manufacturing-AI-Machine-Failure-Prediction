# Smart Manufacturing AI – Machine Failure Prediction

An end-to-end Machine Learning project that predicts industrial machine failures using sensor data and an XGBoost classification model.

## 🚀 Live Demo
[Streamlit Application](https://smart-manufacturing-ai-nzdjnlfuvg4tfjelfjrfjh.streamlit.app/)

## 📊 Dataset
- AI4I 2020 Predictive Maintenance Dataset
- 10,000 records
- Binary classification
- Target: Machine Failure (0/1)

## 🛠️ Technologies
Python | Pandas | NumPy | Scikit-learn | XGBoost | Plotly | Streamlit

## ⚙️ Machine Learning Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Data Preprocessing
6. Model Training
7. Model Evaluation
8. Failure Prediction
9. Dashboard Development
10. Deployment

## 💡 Key Features
- Machine monitoring
- Failure prediction
- Failure probability
- Interactive dashboard
- Model performance evaluation
- CSV upload and analysis
- Prediction history

## ▶️ Run Locally

```bash
git clone https://github.com/ajayvasudevancbe-Datascience/Smart-Manufacturing-AI.git

pip install -r requirements.txt
```
